## 🧩 Selected Academic Work

### 🎓 Bachelor's Thesis — Distributed Application for EU Agricultural Subsidies

Developed the application layer of a **seven-organisation Hyperledger Fabric 3.0 network** for managing EU agricultural subsidies in Greece.

- Built **3 Go chaincodes**
- Developed **6 Go backend services**
- Built **7 React / TypeScript portals**
- Developed a **Manifest V3 browser wallet**
- Implemented local transaction signing using **ECDSA P-256 and the Web Crypto API**
- Used **private data collections** for sensitive data
- Implemented extensive role, transition, frontend and end-to-end testing

### ☁️ ErgoHub — Freelance Marketplace on Azure Kubernetes

Team academic project built with **Spring Boot 3, React/Redux, PostgreSQL and MinIO**.

- Created **Jenkins CI/CD pipelines**
- Built and deployed Docker images through **Azure Container Registry**
- Deployed the application to **Azure Kubernetes Service**
- Configured **NGINX Ingress and Let's Encrypt TLS**
- Used **Ansible** for infrastructure and environment setup

### 🖥️ OpenStack Private Cloud on Google Cloud

Built an OpenStack environment using **DevStack on GCP**, configuring services including Keystone, Glance, Neutron and Nova.

Deployed a three-tier application using:

`Nginx → Flask → PostgreSQL`

and configured networking, floating IP routing and persistent system configuration.

### ⚡ CUDA / High-Performance Computing

Optimised a **4096 × 4096 matrix multiplication** on an NVIDIA T4 GPU from **0.306 s to 0.086 s — approximately 3.6× faster** using tiling and register blocking.
